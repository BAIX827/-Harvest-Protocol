### 关键决定：控制与保护

- 使用真实 GraphEdit / GraphNode，固定传感器→双阈值判断→水泵三种节点；仅允许对应方向 / 类型端口连线，可断开、重连和保存位置。
- 新开放 60 币控制器，安装消耗真实库存。默认手动；切换模式先停泵，自动模式必须完整连线、有效且位于覆盖区的探头，以及正常水路与供电。
- 规则：`读数 < 启动值` 开泵，`读数 >= 停止值` 停泵；中间保持前态。范围为 0～60%，启动必须小于停止，默认 25 / 35%。保护停机清除开泵前态，修复后在中间区间保持停止。
- 控制读取传感器有效值，不读取教学真实值。控制、供水、采样均使用同一固定步；每步供水前判断，步末依据新采样和资源状态复核，避免加速 / 帧批次改变结果。
- 保留手动模式原有玩法；自动模式不能通过手动开关绕过保护。传感器、管路和供电变化立即复核输出，但暂停时不消耗资源。
- 日志只记录状态转换和参数编辑，包含时间、原因、读数及阈值；同时保存连接、模式、前态、输出和必要状态，复核跨程序继续。
