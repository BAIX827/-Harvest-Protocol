# 田野工程师 Fieldworks · Windows 试玩说明

版本：0.1.0-playtest.1。首版单人离线原型，Windows x86_64，Godot 4.7.2 / Compatibility。

## 打开游戏

1. 将 ZIP 完整解压到一个普通文件夹，建议解压到桌面；不要直接在压缩包中打开程序。
2. 双击 `Fieldworks.exe`。同目录的 `Fieldworks.pck` 必须保留，不需要另外安装 Godot、Python 或开发工具。
3. 首次出现农场后，可以按空格暂停，再按 H 查看目标。初始有 600 币和三种作物种子。

本包没有购买或配置代码签名证书。如果 Windows 显示未知发布者，请先核对下载来源及随附 SHA256SUMS.txt；不要关闭系统防护。无法启动时保留错误文字供排查。

## 第一轮怎么玩

1. WASD / 方向键移动。入口右上 `(8,13)` 附近按 **2 翻土 → 3 播种 → 4 浇水**，用左键操作；距离太远需先走近。右键检查地块。
2. 选择顶部 **12×** 加速，照料水分并等生菜成熟，按 **5** 收获。按 **B** 卖出一份生菜，再补买一份种子。
3. **H** 的九项目标会随真实进展更新，依次引导手动供水、参考实验、自动灌溉、故障恢复和自主调整；“定位目标”只选中地块，不替你操作。
4. 完整工程参考套装是 300 L 水箱、节能泵、180 Wh 电池、5 段管道、探头、控制器和首次满水满电，共 493 币。第一份生菜出售及补种后购买，余额 119 币。管路、安装位置与参考坐标见包内 README.md。
5. **L** 做 20% / 40% 两点校准和中点复核，再显式同步到真实探头；**T** 连接“探头→判断→水泵”，使用双阈值自动控制。完成故障演练需真实断线、观察、诊断、修复并恢复自动出水。

## 常用操作

| 操作 | 按键 |
| --- | --- |
| 检查 / 翻土 / 播种 / 浇水 / 收获 | 1 / 2 / 3 / 4 / 5 |
| 换种子 | Q |
| 集市 / 组装 / 测量 / 自动图 / 实验 / 引导 | B / E / I / T / L / H |
| 暂停或继续 | 空格 |
| 返回农场 | Esc；数字输入与下拉菜单会先结束编辑 / 收起 |
| 全图 / 跟随近景 | F，地图内滚轮也可切换 |
| 短操作音开关 | M，重启默认关闭 |
| 地块网格 / 回入口 | G / R |
| 保存 / 读取 | F5 / F9 |

B / E 编辑期间暂时暂停，关闭后恢复原设置；I / T / L / H 保持实际时间。缺水、缺电、断管、探头失效和逻辑断线会保护停泵，界面保留具体原因；不要只看节点的开泵指令。手动模式需要自己监看和关泵。

## 保存和退出

一个手动存档位，**不会自动保存**。按 F5 保存，F9 读取；发现已有档位时先暂停并提示，不会自行覆盖。关闭窗口或点退出时，有未保存游玩进度会提供“保存并退出 / 不保存退出 / 取消”。

存档在 `%APPDATA%\Godot\app_userdata\田野工程师 · Fieldworks\saves\farm-v6.json`，备份是同名 `.bak` 文件。源码版和本包使用同一用户目录；卸载或移动解压文件夹不会自动删除档案。想重新开始时先退出游戏、备份并移开整个 saves 文件夹（包括旧版档）；不要在运行中编辑档案。新建农场需明确按 F5 才覆盖当前档位。

当前格式 v6；同引擎和相应配置一致的 v1～v5 需确认导入，其他版本不承诺兼容。主档损坏时可确认恢复上一次有效备份。读取不会计算离线生长；缩放、声音为会话设置，读档回全图。

## 系统范围与已知限制

- 在本机 Windows x86_64 原生图形环境验收；最低窗口 1152×720，推荐 1440×900 或更大。需要支持 Compatibility 渲染的 OpenGL 驱动。其他电脑 / 显卡和高 DPI 组合未逐一实测。
- 使用系统中文字体，Windows 的 Microsoft YaHei 为首选；未随包分发系统字体。缺少中文字体的精简系统可能显示异常。
- 固定 24×24 农场、三类作物、单探头 / 出口和固定设备台位。程序绘制的 C 方向首版美术，尚无机器人、温室、任意设备摆放或完整科技树。
- 价格、生长、水分和测量均为游戏教学参数；自主调整证明新规则运行，不自动证明节水或最优。
- 无 Mac / ARM 试玩包，无多人、云同步或安装器；未验证实际断电耐久性。短音的生成和触发已检查，扬声器听感未作为验收结论。
